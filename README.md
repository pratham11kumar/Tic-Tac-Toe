# Tic Tac Toe Game

A clean and interactive Tic Tac Toe game built with React featuring a two-player turn system, winner detection, draw detection, animated winning cells, reset functionality, and a responsive UI.

## Features

- 🎮 3×3 Tic Tac Toe Board
- 👥 Two Player Turn System
- 🏆 Winner Detection
- 🤝 Draw Detection
- ✨ Winning Cell Animation
- 🔄 Reset Game Option
- 📱 Responsive Design
- ⚡ Fast and Smooth Gameplay

## Tech Stack

- React
- Vite
- CSS3

## Installation

Clone the repository:


git clone <(https://github.com/pratham11kumar/Tic-Tac-Toe)>


Move to project folder:

```bash
cd Tic-Tac-Toe
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```

## Build for Production

```bash
npm run build
```
